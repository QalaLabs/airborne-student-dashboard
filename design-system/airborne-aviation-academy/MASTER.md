## 1. Official Color System (The 60 / 30 / 10 Rule)

Strict adherence to the 60 / 30 / 10 rule across all digital surfaces:

| Role | Proportion | Color Name | Hex Code | Usage & Placement |
|------|------------|------------|----------|-------------------|
| **Canvas & Surfaces** | **60%** | **Stark White** | `#FFFFFF` | Backgrounds of all study materials, cards, main content area, document containers |
| **Structural UI & Headings** | **30%** | **Captain's Navy** | `#00274C` | Navigation bars, sidebar, primary headings, hero gradients (`#00274C` to `#00172E`), footers, core structural borders |
| **Action & Focal Accent** | **10%** | **Ascend Red** | `#DB241E` | Logo jet, contrail, focal 'O', primary CTA buttons, active state pills, alert badges, progress indicators |
| **Achievement Accent** | *Accent Only* | **Aviation Gold** | `#D8A027` | **EXCLUSIVELY** for 100% Exam Success Rate badge, star ratings, Captain's stripes insignia, milestone trophies. *Never as a primary background.* |
| **Body Copy** | *Text* | **Obsidian Black** | `#212121` | High-contrast body copy on white/light backgrounds, data table values, dense study text |
| **Metadata & Dividers** | *Borders/Meta* | **Mid Grey** | `#8A9BB0` | Subtitles, timestamps, table borders, inactive indicators, airport ICAO codes |
| **Secondary Backgrounds** | *Surfaces* | **Light Grey** | `#F5F6F8` | Platform app background canvas, input backgrounds, alternating table rows |

### ✕ Strictly Retired / Prohibited Colors:
- **Cobalt Blue (`#0000FF`)** — Banned
- **Cherry Red** — Banned (use Ascend Red `#DB241E`)
- **Skyline Blue (`#2F65A7`)** — Banned
- Unapproved neons, purples, or random blues.

## 2. Typographic System

Engineered for dense aviation ground study material legibility and cockpit precision:

| Level | Typeface | Size / Weight | Tracking | Usage |
|-------|----------|---------------|----------|-------|
| **H1 Hero** | **Montserrat** | 32–48px / Bold & Black | +2px tracking | Major page titles, hero headers |
| **H2 Section** | **Montserrat** | 22–28px / Bold | +1px tracking | Section titles, feature headers |
| **H3 Subsection** | **Montserrat** | 16–20px / SemiBold | Normal | Card headers, module titles |
| **Body Copy** | **Roboto** | 13–15px / Regular | Normal (1.5× leading) | Explanations, paragraphs, instructions |
| **Captions / Meta** | **Roboto** | 11–12px / Medium or Light | Normal | Metadata, timestamps, instructor credentials |
| **Telemetry & Data** | **JetBrains Mono** | 11–13px / Medium & Bold | +1px tracking | METAR, VOR coordinates, roll numbers, fees, timestamps |

## 3. UI/UX Pro Max Rules & Execution Standards

1. **Zero Emoji Icons**: Emojis (e.g. ✈, ✅, ⚠️, 🚀) are strictly prohibited as UI icons. Use Lucide SVG icons with uniform 1.5–2px stroke weight.
2. **Aerodynamic Cuts & Chamfers**: Use subtle aerodynamic angled cuts (`aerodynamic-cut`, `aerodynamic-tag`) echoing the Airborne aircraft silhouette.
3. **Touch & Interaction**:
   - All interactive elements must have `cursor-pointer`
   - Minimum 44×44px touch targets on mobile
   - Transitions: 150–250ms ease-out (smooth, no layout shifts)
4. **Accessibility (WCAG AA)**:
   - High text contrast >= 4.5:1 against all backgrounds
   - Visible focus rings with brand outline (`focus-visible:ring-2 focus-visible:ring-[#DB241E]`)
   - All icon buttons must provide `aria-label`
